# Zoo — Design Context

## Design Context

### Users
- Developers and platform engineers who run AI agents (Claude Code, computer-use agents, MCP clients) and want isolated, disposable machines for them. Self-hosters and privacy-conscious teams.
- They arrive from GitHub, HN or docs links, decide in under a minute what Zoo does, and want the install command fast.
- Job to be done: run self-hosted microVM sandboxes (Linux/macOS/Windows desktops, browsers, code shells), let agents drive them over MCP/REST/SDK, and watch or take over from a dashboard.

### Brand Personality
- Technical, trustworthy, precise. Three words: **engineered, calm, honest**.
- Voice: plain, factual, no hype. Emotional goal: "serious infrastructure I can run myself" — control-room energy, not startup glow.

### Aesthetic Direction
- Dark theme: warm-tinted charcoal neutrals (hue ≈107, matching the dashboard palette). Never pure black.
- Accent: petrol teal from the brand badge (`#4a8a9e` family), used sparingly (~10%) for interactive and live elements. Green/amber reserved for running/stopped status.
- Type: Archivo Variable — expanded width (font-stretch ~125%) for display, normal width for body. Fragment Mono for machine facts: commands, labels, stats, section indexes.
- Structure is visible: hairline rules, mono section indexes ("01 / OVERVIEW"), left-aligned asymmetric layouts, spec tables instead of identical card grids.
- Reference: opencode.ai — clarity of offer, install command in the first viewport, scannable features, FAQ.
- Anti-references: no purple-blue gradients, no neon-cyan-on-dark glow, no glassmorphism, no icon-card grids, no big-number metric template, no decorative sparklines.

### Design Principles
1. **State the offer plainly.** What it is and how to install it, inside the first viewport.
2. **Machine facts in mono, prose in the grotesque.** Show real commands and real tool names — never invent product behavior.
3. **Structure is visible.** Hairlines, indexes and tables read like a control-plane schematic.
4. **Accent is rare.** Teal marks interactive and live things only; status colors mean state.
5. **Everything traces to the docs.** Copy on the marketing site must be faithful to `docs/*.md`.
