Zoo provides Linux, macOS and Windows sandboxes with REST, MCP and SDK tools.
It does not host a model, planner, task execution service or chat connector — bring
your own agent and drive it over [MCP](/docs/get-started/mcp/).

Start a sandbox and take a screenshot in a few lines:

```bash
pip install 'zoo-sdk[cli]'
zoo login --url http://localhost:8000
```

```python
from zoo_sdk import Zoo

with Zoo().sandbox(kind="desktop") as box:  # deleted on exit
    png = box.screenshot()
```

## Scope of validation

Implementation and static builds are not runtime acceptance. Real Kata/CSI/native VM
recovery, unique saved-state slots, whole-VM pause and measurements remain deferred.
[Performance targets](/docs/reference/performance/) are goals, not benchmark results.
